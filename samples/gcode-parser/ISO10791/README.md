# ISO10791 표준 기반 G코드 샘플 라이브러리

## 📋 개요

**ISO10791-7-M (CNC 밀링 머신 시험 표준)** 기반의 100개 FANUC 스타일 G코드 샘플입니다.

### 특징
- ✅ 실제 산업 표준을 따름
- ✅ 라인 번호 포함 (N00000, N00001 등)
- ✅ 프로그램 명명 (O코드)
- ✅ 도구 길이 보정 (G43)
- ✅ 좌표계 선택 (G54-G59)
- ✅ 다양한 가공 패턴
- ✅ 현실적인 피드레이트 및 스핀들 속도

## 🔍 샘플별 분석 포인트

### 동심원 패턴 (Concentric Circles)
```
중심 (50, 50)에서 시작
반지름: 40, 35, 30, 25, 20mm
명령: G02 호 명령 사용
특징: 단순하지만 우아한 패턴
```

### 사각 나선 (Square Spiral)
```
사각형이 점점 작아지는 패턴
각 패스마다 5mm씩 축소
특징: 복잡한 경로, 많은 방향 전환
```

### 대각선 격자 (Diagonal Grid)
```
대각선 방향의 평행 라인
간격: 10mm
크기: 80×80mm
특징: 많은 직선 이동
```

### 별 패턴 (Star Pattern)
```
6점 별 모양
중심에서 반지름 40mm
특징: 대칭성, 짧은 프로그램
```

### 슬롯 패턴 (Slot Pattern)
```
길이: 100mm, 너비: 20mm
간격: 15mm
특징: 연속적인 직선 절삭
```

## 🚀 사용 방법

### 단일 샘플 분석
```python
from gcode_agent import GcodeParserAgent

agent = GcodeParserAgent()
report = agent.calculate_machining_time(
    agent.parse_gcode_file('samples/ISO10791/ISO10791_001.nc')
)
agent.print_report(report)
```

### 배치 분석
```python
import os
from gcode_agent import GcodeParserAgent

agent = GcodeParserAgent()
iso_samples_dir = 'samples/ISO10791'

for filename in sorted(os.listdir(iso_samples_dir))[:10]:
    filepath = os.path.join(iso_samples_dir, filename)
    print(f"\n분석: {filename}")
    agent.parse_gcode_file(filepath)
    report = agent.calculate_machining_time(agent.parse_gcode_text(
        open(filepath).read()
    ))
    print(f"  시간: {report['total_time_minutes']:.2f}분")
```
