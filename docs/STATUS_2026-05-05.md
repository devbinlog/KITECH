### 1.3 Agent-Orchestrator 내부 구조 (LangGraph)

```
WS /ws/chat (인증: NEXT_PUBLIC_AGENT_WS_TOKEN = INTERNAL_SERVICE_KEY)
   ↓
StateGraph — env-driven dispatch
┌──────────────────────────┬──────────────────────────┐
│  ORCHESTRATOR_PIPELINE   │  ORCHESTRATOR_PIPELINE   │
│  =react (default)        │  =multi_agent (opt-in)   │
├──────────────────────────┼──────────────────────────┤
│ intent_classify          │ planner                  │
│   ↓ (nl-router /classify)│   ↓                      │
│ reasoning ↔ tool_call    │ executor ↔ tool_call     │
│   ↓                      │   ↓                      │
│ END                      │ critic → END             │
└──────────────────────────┴──────────────────────────┘
   ↓
AsyncSqliteSaver (체크포인트, 모듈 레벨 conn 유지)
   ↓
tool_loader: registry YAML → StructuredTool
   ↓
듀얼 헤더 (X-Internal-Key + X-Internal-Service-Key)
   ↓
/capabilities 보유 서비스로 POST/GET
```

LLM Provider: `LLM_PROVIDER=mock|slm|real` 환경변수 스위칭. 현재 **Mock**으로 운영 중.
