# [MES] 시스템 화면 설계서 (UI/UX Specifications) v3.0

## 1. 개요 (Overview)
* **프로젝트:** 스마트 공장 생산 관리 시스템 (MES) 표준 플랫폼
* **버전:** 3.0
* **주요 변경 (v3):**
    * **AAS 연동:** 설비 관리 화면에 **'자산 동기화(Asset Discovery)'** 버튼 및 기능 추가.
    * **데이터 시각화:** 설비별 상세 팝업에 **JSONB 데이터(Spec, Real-time)** 뷰어 적용.
    * **기존 기능 유지:** v2의 NC 파일 매핑 및 물류 시나리오 분리 로직 완벽 포함.
* **디자인 컨셉:** Clean Industrial (Blue & White), 직관적인 데이터 시각화
* **해상도 기준:** Desktop (1920x1080)
* **구현 기술:** Next.js 14, Shadcn/UI, Tailwind CSS, ReactFlow

---

## 3. 개발 참고 사항 (Dev Notes)

* **UI Library:** `Shadcn/UI` (Card, Dialog, Table, Badge 등) 활용.
* **Icons:** `Lucide React` (산업용 아이콘 스타일).
* **Visualization:** `ReactFlow` (공정 라우팅), `Recharts` (대시보드 차트).
* **JSON Viewer:** 설비 상세 정보 표시 시 `react-json-view` 등 라이브러리 활용 권장.
* **Data Refresh:** `TanStack Query`의 `refetchInterval`을 활용하여 대시보드 및 설비 상태 3~5초 주기 갱신.
* **Deployment:** Windows Standalone (Next.js `output: standalone`).
